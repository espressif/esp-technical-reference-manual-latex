{\bfseries Notes: }\\
``YES" indicates that the block exists; ``NO" indicates that the block does not exist; ``$0^{256}$" indicates a bit string that consists of 256-bit zeros.
Note that using $0^{256}$ as $\mathit{Key}$ is not secure. We strongly recommend to configure a valid key.
