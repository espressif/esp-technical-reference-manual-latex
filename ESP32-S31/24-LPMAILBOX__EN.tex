\hypertarget{lpmailbox}{}
\chapter{LP Mailbox}
\label{mod:lpmailbox}

\section{Overview}


\chipname{} integrates an LP Mailbox module that provides an efficient inter-core communication mechanism between the LP CPU and HP CPU0/1. The LP Mailbox module comprises sixteen 32-bit message registers that the LP CPU and HP CPU0/1 can use to store and exchange messages. Inter-core communication between LP CPU and HP CPU0/1 is achieved through an interrupt mechanism implemented within the LP Mailbox module.

\section{Features}
\chipname{} LP Mailbox has the following features:
\begin{itemize}
    \item Sixteen 32-bit message registers for inter-core communication
    \item LP CPU external interrupt signal: \hyperref[tab:lpmailbox-int-sources]{MB\_LP\_INTR}
    \item HP CPU\regindex{x} (\regindex{x}: 0$\sim$1) external interrupt signal: \hyperref[tab:lpmailbox-int-sources]{MB\_HP\_INTR}
\end{itemize}

\subsection{Message Registers}
The LP Mailbox provides sixteen 32-bit message registers in total, denoted as \hyperref[regdesc:MBMESSAGE0REG]{MB\_MESSAGE\_0\_REG}$\sim$\hyperref[regdesc:MBMESSAGE15REG]{MB\_MESSAGE\_15\_REG}, for caching inter-core communication messages. Both LP CPU and HP CPU0/1 can read and write these message registers to pass or retrieve messages.

Reading and writing message registers is done through the APB bus, using LP\_PERI\_CLK, which is the only clock in LP Mailbox. For more information about the clock, please refer to Chapter \ref{mod:resclk} \textit{\nameref{mod:resclk}}.

\subsection{Interrupts}
\label{sec:lpmailbox-interrupt}


\chipname{} LP Mailbox can generate the following external interrupt signals:
    \begin{itemize}
        \item MB\_LP\_INTR
        \item MB\_HP\_INTR
    \end{itemize}
MB\_LP\_INTR is directly mapped to LP CPU (see \textit{\nameref{mod:ulp}}), and MB\_HP\_INTR can be mapped to HP CPU0/1 through the \hyperref[mod:intmtrx]{Interrupt Matrix}.
These interrupt signals are generated by internal interrupt sources of the LP Mailbox module. Table \ref{tab:lpmailbox-int-sources} lists the internal interrupt sources, interrupt enable conditions, interrupt trigger conditions, interrupt clear conditions, and generated interrupt signals of the LP Mailbox. An internal interrupt source is generated only when the interrupt enable condition is met and the interrupt trigger condition is satisfied. When the interrupt clear condition is met, the internal interrupt source is cleared.

\begin{longtable}{ | L{2.3cm} | L{3.8cm} | L{3.9cm} | L{4.2cm} | L{2.2cm} | }
\caption{LP Mailbox's Internal Interrupt Sources} \label{tab:lpmailbox-int-sources}
\\ \hline
\rowcolor{lightgray}
\textbf{Internal Interrupt Source} & \textbf{Interrupt Enable Condition} & \textbf{Interrupt Trigger Condition} & \textbf{Interrupt Clear Condition} & \textbf{Interrupt Signal}\\ \hline
\label{int:MBHPmINT} MB\_HP\_\regindex{i}\_INT & \hyperref[fielddesc:MBHP0INTENA]{MB\_HP\_\regindex{i}\_INT\_ENA} is 1 & Write to MB\_MESSAGE\_\regindex{i}\_REG & Write 1 to \hyperref[fielddesc:MBHP0INTCLR]{MB\_HP\_\regindex{i}\_INT\_CLR} & MB\_HP\_INTR  \\ \hline
\label{int:MBLPnINT} MB\_LP\_\regindex{i}\_INT & \hyperref[fielddesc:MBLP0INTENA]{MB\_LP\_\regindex{i}\_INT\_ENA} is 1 & Write to MB\_MESSAGE\_\regindex{i}\_REG & Write 1 to \hyperref[fielddesc:MBLP0INTCLR]{MB\_LP\_\regindex{i}\_INT\_CLR} & MB\_LP\_INTR  \\ \hline
\end{longtable}
\begin{tiplisting}
\vspace{-2em}
\begin{itemize}
    \item \regindex{i} ranges from 0$\sim$15.
    \item The LP Mailbox does not identify which CPU is accessing it. As long as the trigger conditions in Table \ref{tab:lpmailbox-int-sources} are met, an interrupt is generated or cleared.
    \item \hyperref[tab:lpmailbox-int-sources]{MB\_HP\_INTR} can also serve as an external interrupt source for LP CPU and be mapped to LP CPU by LP\_INTR\_MAP as illustrated in Figure \ref{fig:lpmbsysdigram}. For more information about LP\_INTR\_MAP, please refer to Chapter \ref{mod:ulp} \textit{\nameref{mod:ulp}}.
    \item\hyperref[tab:lpmailbox-int-sources]{MB\_LP\_INTR} can also serve as an external interrupt source for HP CPU\regindex{x} and can be mapped to HP CPU\regindex{x} through the \hyperref[mod:intmtrx]{Interrupt Matrix}.
    \item When the LP Mailbox is required to assign different interrupt sources for HP CPU0 and HP CPU1, it can map \hyperref[tab:lpmailbox-int-sources]{MB\_HP\_INTR} and  \hyperref[tab:lpmailbox-int-sources]{MB\_LP\_INTR} independently to HP CPU0 and HP CPU1 using the \hyperref[mod:intmtrx]{Interrupt Matrix}.
\end{itemize}
\end{tiplisting}

\subsection{Inter-Core Communication}
When communication is required between LP CPU and HP CPU\regindex{x}, a subset of or all message registers in the LP Mailbox can be utilized to share messages as needed. The synchronization of messages can be achieved through the corresponding interrupts. During communication, software must ensure that only the sender is allowed to write to the message registers to prevent data corruption.

\begin{itemize}
    \item Example of initiating communication from HP CPU0 to LP CPU using MB\_MESSAGE\_\regindex{i}\_REG:
    \begin{itemize}
        \item Configure the LP interrupt mapping module (LP\_INTR\_MAP, see Figure \ref{fig:lpmbsysdigram}) to map the MB\_LP\_\regindex{i}\_INT interrupt to LP CPU.
        \item Set \hyperref[fielddesc:MBLP0INTENA]{MB\_LP\_\regindex{i}\_INT\_ENA} to enable the MB\_LP\_\regindex{i}\_INT interrupt.
        \item HP CPU0 writes to \hyperref[regdesc:MBMESSAGE0REG]{MB\_MESSAGE\_\regindex{i}\_REG}, caching shared messages.
        \item LP CPU detects the interrupt and enters the interrupt handler. In the interrupt handler, it checks the \hyperref[regdesc:MBLPINTSTREG]{MB\_LP\_INT\_ST\_REG} interrupt status register, finds the \hyperref[fielddesc:MBLP0INTST]{MB\_LP\_\regindex{i}\_INT\_ST} status bit set, and determines that the MB\_LP\_\regindex{i}\_INT interrupt has occurred.
        \item LP CPU reads \hyperref[regdesc:MBMESSAGE0REG]{MB\_MESSAGE\_\regindex{i}\_REG} to retrieve shared message.
        \item LP CPU writes 1 to the {MB\_LP\_\regindex{i}\_INT\_CLR} bit of the \hyperref[regdesc:MBLPINTCLRREG]{MB\_LP\_INT\_CLR\_REG} register, which triggers the interrupt clear action.
        \item LP CPU reads the \hyperref[regdesc:MBLPINTSTREG]{MB\_LP\_INT\_ST\_REG} interrupt status register until the \hyperref[fielddesc:MBLP0INTST]{MB\_LP\_\regindex{i}\_ST} status bit is cleared. Then LP CPU exits the interrupt handler.
    \end{itemize}
    \item Example of initiating communication from LP CPU to HP CPU0:
    \begin{itemize}
        \item Configure the \hyperref[mod:intmtrx]{Interrupt Matrix} to map MB\_HP\_INTR to HP CPU0. See Chapter \ref{mod:intmtrx} \textit{\nameref{mod:intmtrx}}.
        \item Set \hyperref[fielddesc:MBHP0INTENA]{MB\_HP\_\regindex{i}\_INT\_ENA} to enable the MB\_HP\_\regindex{i}\_INT interrupt.
        \item LP CPU writes to \hyperref[regdesc:MBMESSAGE0REG]{MB\_MESSAGE\_\regindex{i}\_REG}, caching shared messages.
        \item HP CPU0 detects the interrupt and enters the interrupt handler. In the interrupt handler, it checks the \hyperref[regdesc:MBHPINTSTREG]{MB\_HP\_INT\_ST\_REG} interrupt status register, finds the \hyperref[fielddesc:MBHP0INTST]{MB\_HP\_\regindex{i}\_INT\_ST} status bit set, and determines that the MB\_HP\_\regindex{i}\_INT interrupt has occurred.
        \item HP CPU0 reads \hyperref[regdesc:MBMESSAGE0REG]{MB\_MESSAGE\_\regindex{i}\_REG} to retrieve shared messages.
        \item HP CPU0 writes 1 to the {MB\_HP\_\regindex{i}\_INT\_CLR} bit of the \hyperref[regdesc:MBHPINTCLRREG]{MB\_HP\_INT\_CLR\_REG} register, which triggers the interrupt clear action.
        \item HP CPU0 reads the \hyperref[regdesc:MBHPINTSTREG]{MB\_HP\_INT\_ST\_REG} interrupt status register until the \hyperref[fielddesc:MBHP0INTST]{MB\_HP\_\regindex{i}\_ST} status bit is cleared. Then HP CPU0 exits the interrupt handler.
    \end{itemize}
\end{itemize}
