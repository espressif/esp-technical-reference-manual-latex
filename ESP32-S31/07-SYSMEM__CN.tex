\chapter{系统和存储器}
\label{mod:sysmem}

\section{概述}

\chipname{} 是一个超低功耗和高度集成的系统，集成了：
\begin{itemize}
    \item 一颗高性能 RISC-V 32 位双核处理器 (HP CPU)，五级流水线架构，主频高达 320 MHz
    \item 一颗低功耗 RISC-V 32 位单核处理器 (LP CPU)，二级流水线架构，主频高达 40 MHz
\end{itemize}

所有的内部存储器、外部存储器以及外设都分布在 HP CPU 和 LP CPU 的总线上。

\section{主要特性}

\begin{itemize}
    \item {\bfseries 地址空间}
        \begin{itemize}
    	    \item 864 KB 内部存储器空间，可被指令总线或数据总线访问
    	    \item 2464 KB 外设地址空间
    	    \item 320 MB 外部存储器虚拟地址空间，可被指令总线或数据总线访问
    	    \item 512 KB 内部 DMA 地址空间
                \item 320 MB 外部 DMA 地址空间
        \end{itemize}
    \item {\bfseries 内部存储器}
        \begin{itemize}
            \item 320 KB ROM
	        \item 512 KB HP SRAM
	        \item 32 KB LP SRAM
	    \end{itemize}
    \item {\bfseries 外部存储器}
        \begin{itemize}
            \item 最大支持 256 MB 片外 flash
            \item 最大支持 64 MB 片外 RAM
	    \end{itemize}
    \item \textbf{外设空间}
        \begin{itemize}
           \item 多个模块/外设（详见表 \ref{tab:sysmem-base-address}）
        \end{itemize}
    \item {\bfseries GDMA}
        \begin{itemize}
            \item 6 个模块/外设支持 HP GDMA-AHB
            \item 2 个模块/外设支持 LP GDMA-AHB
            \item 7 个模块/外设支持 GDMA-AXI
        \end{itemize}
\end{itemize}

\section{功能描述}

\subsection{地址映射}

图 \ref{fig:sysmem-address-mapping-structure} 展示了系统结构与地址映射结构。所有非保留地址均可通过指令总线和数据总线进行访问，即指令总线和数据总线访问的地址空间一样。HP CPU 和 LP CPU 的数据总线与指令总线均为小端序。所有总线均为 32 位数据宽度。HP CPU 和 LP CPU 均可以通过数据总线进行单字节、双字节、四字节的数据访问。

HP CPU 支持：
\begin{itemize}
\item 直接通过数据总线和指令总线访问内部存储器。
  \begin{itemize}
        \item 512 KB HP SRAM (0x2F00\_0000 \verb+~+ 0x2F07\_FFFF)
        \item 32 KB LP SRAM  (0x2E00\_0000 \verb+~+ 0x2E00\_7FFF)
    \end{itemize}
\item 通过 \hyperlink{par:rom}{ROM-Cache} 访问内部存储器。
    \begin{itemize}
        \item 320 KB ROM (0x2F80\_0000 \verb+~+ 0x2F84\_FFFF)
    \end{itemize}

\begin{tiplisting}
软件可以以 cacheable 或 non-cacheable 的方式访问 ROM 的地址。其中 cacheable 访问方式是指通过 cache 进行访问；non-cacheable 访问方式是不通过 cache 进行直接访问。cacheable 访问还是 non-cacheable 访问则是由 CPU PMA (Physical Memory Attribution) 控制。
\end{tiplisting}
\item 通过 cache 访问外部存储器，虚地址经过 MMU 映射到外部存储器的实地址空间。
    \begin{itemize}
        \item 多达 256 MB 外部 flash (0x4000\_0000 \verb+~+ 0x4FFF\_FFFF)
        \item 多达 64 MB 外部 RAM (0x5000\_0000 \verb+~+ 0x53FF\_FFFF)
    \end{itemize}
\item 直接通过数据总线访问外部存储器（速度较慢，通常用于调试），虚地址经过 MMU 映射到外部存储器的实地址空间。
    \begin{itemize}
        \item 多达 256 MB 外部 flash，直接访问的地址段为 0xA000\_0000 \verb+~+ 0xAFFF\_FFFF。HP CPU 发出该地址后，会先被映射到 0x4000\_0000 \verb+~+ 0x4FFF\_FFFF。
        \item 多达 64 MB 外部 RAM，直接访问的地址段为 0xC000\_0000 \verb+~+ 0xC3FF\_FFFF。HP CPU 发出该地址后，会先被映射到 0x5000\_0000 \verb+~+ 0x53FF\_FFFF。
    \end{itemize}
\item 直接通过数据总线访问模块/外设。
    \begin{itemize}
        \item HP 外设
        \item LP 外设
        \item CPU 外设
        \item 调试外设
    \end{itemize}
\end{itemize}

LP CPU 支持：
\begin{itemize}
    \item 直接通过数据总线和指令总线访问 HP SRAM 和 LP SRAM。
     \begin{itemize}
        \item 512 KB HP SRAM (0x2F00\_0000 \verb+~+ 0x2F07\_FFFF)
        \item 32 KB LP SRAM  (0x2E00\_0000 \verb+~+ 0x2E00\_7FFF)
    \end{itemize}
\item 直接通过数据总线访问外部存储器，虚地址经过 MMU 映射到外部存储器的实地址空间。
    \begin{itemize}
        \item 多达 256 MB 外部 flash (0x4000\_0000 \verb+~+ 0x4FFF\_FFFF)
        \item 多达 64 MB 外部 RAM (0x5000\_0000 \verb+~+ 0x53FF\_FFFF)
    \end{itemize}    
    \item 直接通过数据总线访问模块/外设。
    \begin{itemize}
        \item HP 外设
        \item LP 外设
        \item CPU 外设
        \item 调试外设
    \end{itemize}
\end{itemize}

\subsection{内部存储器}
\label{para:sysmem-internal-memory}

\chipname{} 的内部存储器包含如下三种类型：

\begin{itemize}
    \item ROM (320 KB)：只读存储器，不可编程，仅可由 HP CPU 访问。用于存放系统底层软件的 ROM 代码和只读数据。
    \item HP SRAM (512 KB)：易失性存储器，可响应 HP CPU 和 LP CPU 的访问请求。HP CPU 的访问延迟通常是一个 HP CPU 时钟周期。
    \item LP SRAM (32 KB)：以静态 RAM (SRAM) 方式实现，因此也是易失性存储器。但在 Deep-sleep 模式下，存放在 LP SRAM 中的数据不会丢失。LP SRAM 可被 HP CPU 和 LP CPU 访问，通常用来存放一些在睡眠模式下仍需保持的程序指令和数据。
\end{itemize}


\subsubsection{ROM}
\label{par:rom}

ROM 的容量为 320 KB，只读。如表 \ref{tab:sysmem-memory} 所示，HP CPU 可以通过指令总线或数据总线地址段 0x2F80\_0000 \verb+~+ 0x2F84\_FFFF 借助 ROM-Cache 访问这部分存储器（见图 \ref{fig:sysmem-rom-cache-arch}），可通过 PMA 将访问类型设定为 non-cacheable 或 cacheable。

\chipname{} ROM-Cache 为 2 路组相联，容量为 4 KB，块大小（即 cache line）为 64 B。指令总线和数据总线可以同时访问该 ROM-Cache，ROM-Cache 经过仲裁对其中一个做出响应。当 ROM-Cache 缺失时，ROM-Cache 控制器会向 ROM 发起请求。

\subsubsection{HP SRAM}
\label{other:sysmem-internal-sram-0}

HP SRAM 的容量为 512 KB，可读可写。如表 \ref{tab:sysmem-memory} 所示，HP CPU 和 LP CPU 可以通过数据总线或指令总线访问这部分存储器。


\subsubsection{LP SRAM}

LP SRAM 容量为 32 KB，为可读可写的 SRAM。如表 \ref{tab:sysmem-memory} 所示，HP CPU 和 LP CPU 可以通过数据总线和指令总线的共用地址段 0x2E00\_0000 \verb+~+ 0x2E00\_7FFF 访问这部分存储器。


\subsection{外部存储器}
\label{para:sysmem-external-memory}


\chipname{} 通过两套独立的 MSPI 控制器（Flash MSPI 与 PSRAM MSPI）分别连接外部 flash 与外部 RAM，Flash MSPI 支持以 SPI、Dual SPI、Quad SPI、QPI 等接口形式连接，PSRAM MSPI 支持以 Octal SPI、OPI 等接口形式连接。\chipname{} 还支持以下安全机制，用以保护用户存储在外部 flash 和 RAM 中的数据：
\begin{itemize}
    \item 支持基于 XTS-AES 的硬件手动加密和自动解密功能，从而保护开发者外部 flash 中的程序和数据。
    \item 支持基于 XTS-AES 的自动加解密功能，从而保护开发者外部 RAM 中的数据。
\end{itemize}


\subsubsection{外部存储器地址映射}

HP CPU 访问外部存储器有两种方式：
\begin{itemize}
    \item 经高速缓存 (cache) 访问
    \item 不经 cache 的直接访问（速度较慢，通常用于调试）
\end{itemize}

对于外部 flash：
\begin{itemize}
    \item 经 cache 访问的地址段为 0x4000\_0000 \verb+~+ 0x4FFF\_FFFF。
    \item 直接访问的地址段为 0xA000\_0000 \verb+~+ 0xAFFF\_FFFF。HP CPU 发出该地址后，会先被映射到 0x4000\_0000 \verb+~+ 0x4FFF\_FFFF。
\end{itemize}
GDMA-AXI 等外设也可以访问外部 flash。内存管理单元 (Memory Management Unit, MMU) 将 HP CPU 和 GDMA-AXI 等外设的地址 (0x4000\_0000 \verb+~+ 0x4FFF\_FFFF) 映射为外部 flash 的实地址。该 MMU 的页大小支持 32 KB、64 KB、128 KB 和 256 KB 四种配置。经过地址映射，\chipname{} 最大支持 256 MB 片外 flash。

对于外部 RAM：
\begin{itemize}
    \item 经 cache 访问的地址段为 0x5000\_0000 \verb+~+ 0x53FF\_FFFF。
    \item 直接访问的地址段为 0xC000\_0000 \verb+~+ 0xC3FF\_FFFF。HP CPU 发出该地址后，会先被映射到 0x5000\_0000 \verb+~+ 0x53FF\_FFFF。
\end{itemize}
GDMA-AXI 等外设也可以访问外部 RAM。MMU 将 HP CPU 和 GDMA-AXI 等外设的地址 (0x5000\_0000 \verb+~+ 0x53FF\_FFFF) 映射为外部 RAM 的实地址。该 MMU 的页大小支持 8 KB、16 KB、32 KB 和 64 KB 四种配置。经过地址映射，\chipname{} 最大支持 64 MB 片外 RAM。

请注意，指令总线与数据总线共用上述地址空间（外部 flash 为 256 MB，外部 RAM 为 64 MB）。

\subsubsection{Cache}


如图 \ref{fig:sysmem-cache-arch} 所示，\chipname{} 采用每个 HP CPU Core（HP CPU0 和 HP CPU1）私有指令 cache，两个 HP CPU Core 共享数据 cache 的结构。指令 cache 的大小为 32 KB，块大小为 64 B，bank 数为 1，两路组相联。数据 cache 的大小为 64 KB，块大小为 64 B，bank 数为 4，两路组相联。当 cache 缺失时，cache 控制器会向外部存储器发起请求。

\subsubsection{Cache 操作}

\chipname{} cache 支持如下几种操作：

\begin{enumerate}
\item \textbf{回写 (Write-back)}
\begin{itemize}
    \item 清除标记存储器中的脏位，并将新数据更新到外部存储器。
    \item 回写操作完成后，新数据将被更新到外部存储器中。
    \item 可以选择是否对 cache 中的数据作失效 (invalidate) 处理。
    \item 如果没有选择失效处理，那么 HP CPU 可以直接从 cache 读取/写入数据，而不会发生 cache 缺失。
    \item 该操作包括两种类型：
    \begin{itemize}
    \item 指定区域回写：仅对 cache 中落入指定区域的数据做回写处理，最小单位为 1 个 cache 块。
    \item 整体回写：对 cache 中的所有数据做回写处理。
    \end{itemize}
\end{itemize}

\item \textbf{清除 (Clean)}
\begin{itemize}
    \item 清除标记存储器中的脏位，但不把新数据更新到外部存储器。
    \item 清除操作完成后，外部存储器中存储的仍然是旧数据，而 cache 会保留新的数据，但 cache 并不知道其存储的为新数据。
    \item 然后 HP CPU 可以直接从 cache 读取/写入数据，而不会发生 cache 缺失。
    \item 该操作包括两种类型：
    \begin{itemize}
    \item 指定区域清除：仅对 cache 中落入指定区域的数据做清除处理，最小单位为 1 个 cache 块。
    \item 整体清除：对 cache 中的所有数据做清除处理。
    \end{itemize}
\end{itemize}

\item \textbf{失效 (Invalidate)}
\begin{itemize}
    \item 清除标记存储器中的有效位，用于删除 cache 中的有效数据。
    \item 该操作完成后，删除的数据将仅存于外部存储器中。
    \item 如果 HP CPU 接着去访问该数据，那么需要访问外部存储器。
    \item 该操作包括两种类型：
    \begin{itemize}
    \item 指定区域失效：仅对 cache 中落入指定区域的数据做失效处理，最小单位为 1 个 cache 块。
    \item 整体失效：对 cache 中的所有数据做失效处理。
    \end{itemize}
\end{itemize}

\item \textbf{预取 (Preload)}
\begin{itemize}
    \item 将指令和数据提前加载到 cache 中。
    \item 预取操作的最小单位为 1 个 cache 块。
    \item 该操作包括两种类型：
    \begin{itemize}
    \item 手动预取 (Manual-Preload)：硬件按软件指定的虚地址预取一段连续的数据。
    \item 自动预取 (Auto-Preload)：硬件根据当前命中/缺失（取决于配置）的地址，自动预取一段连续的数据。
    \end{itemize}
\end{itemize}

\item \textbf{锁定/解锁 (Lock/Unlock)}
\begin{itemize}
    \item 保护 cache 中的数据不被替换掉。
    \item 该锁定操作包括两种类型：
    \begin{itemize}
    \item 预锁定：在填充缺失数据到 cache 时，如果该数据落在指定区域，cache 则将该数据锁定，未落入指定区域的数据不会被锁定。
    \item 手动锁定：检查 cache 中的数据，并将落在指定区域的数据锁定，未落入指定区域的数据不会被锁定。
    \end{itemize}
    \item 当缺失发生时，cache 会优先替换掉未被锁定的那一路的数据，因此锁定区域的数据会一直保存在 cache 中。
    \item 但当所有路都被锁定时，cache 将进行正常替换，就像所有路都没有被锁定一样。
    \item 解锁是锁定的逆操作，但解锁只有手动解锁。
    \item 请注意，回写、清除和指定区域失效操作只对未被锁定的数据起作用。如需对已锁定的数据执行这些操作，请先解锁这些数据。

\end{itemize}
\end{enumerate}


\subsection{GDMA 地址空间}

\chipname{} 支持 HP/LP AHB 通用直接内存访问 (HP/LP GDMA-AHB) 和 HP AXI 通用直接内存访问 (HP GDMA-AXI)，均可提供直接内存访问服务。此外，高速 USB 2.0、RISC-V Trace、2D-DMA 等主机模块也内置了 DMA 功能，同样可以提供直接内存访问服务。

上述所有支持 DMA 的主机模块都可以访问：
\begin{itemize}
    \item HP SRAM (0x2F00\_0000 \verb+~+ 0x2F07\_FFFF)
    \item LP SRAM  (0x2E00\_0000 \verb+~+ 0x2E00\_7FFF)
    \item 外部 flash (0x4000\_0000 \verb+~+ 0x4FFF\_FFFF)
    \item 外部 RAM (0x5000\_0000 \verb+~+ 0x53FF\_FFFF)
    \end{itemize}

\begin{tiplisting}
当使用 DMA 访问任何存储器时，都需要获取对应的访问权限，否则访问将会失败。关于权限管理的更多信息，请参考章节 \ref{mod:permctrl} \textit{\nameref{mod:permctrl}}。
\end{tiplisting}
