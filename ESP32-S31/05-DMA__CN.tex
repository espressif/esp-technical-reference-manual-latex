\hypertarget{dma}{}
\chapter{通用 DMA 控制器 (GDMA-AHB, GDMA-AXI)}
\label{mod:dma}
\section{概述}

通用直接存储访问 (General Direct Memory Access, GDMA) 用于在外设与存储器之间以及存储器与存储器之间提供高速数据传输。借助 GDMA，软件可在无需 CPU 干预的情况下快速传输数据，从而降低 CPU 负载并提高系统效率。

\chipname{} 有两种 GDMA 控制器，分别可直接访问 AHB 总线和 AXI 总线，下文分别简称为 GDMA-AHB 和 GDMA-AXI。其中，GDMA-AHB 根据高性能系统和低功耗系统的区别，又分为 GDMA-AHB-HP 和 GDMA-AHB-LP。GDMA 通道由支持 GDMA 功能的外设共享，用户可将通道分配给任一支持 GDMA 功能的外设。
\begin{itemize}
    \item GDMA-AHB-HP：10 个独立通道，包含 5 个发送通道和 5 个接收通道。支持的外设包括 UHCI、I2S、RMT、音频采样率转换器 (ASRC) 和 CORDIC 加速器。
    \item GDMA-AHB-LP：4 个独立通道，包含 2 个发送通道和 2 个接收通道。支持的外设包括 ADC 和 DAC。
    \item GDMA-AXI：6 个独立通道，包含 3 个发送通道和 3 个接收通道。支持的外设包括 LCD、CAM、两个通用 SPI、PARLIO、AES 和 SHA。
\end{itemize}


GDMA-AHB-HP 和 GDMA-AHB-LP 除通道数和支持的外设不同外，功能完全一致。下文以 GDMA-AHB-HP 为例进行说明，相关描述同样适用于 GDMA-AHB-LP，对应寄存器将 \texttt{AHB\_DMA\_} 前缀替换为 \texttt{LP\_AHB\_DMA\_} 即可。下文如无特殊说明，GDMA-AHB 指代 GDMA-AHB-HP 和 GDMA-AHB-LP，GDMA 指代 GDMA-AHB 和 GDMA-AXI。

在 \chipname{} 上，GDMA-AHB 和 GDMA-AXI 均可访问内部和外部存储器。GDMA-AHB 和 GDMA-AXI 支持可配置的通道间优先级和权重仲裁，以满足不同外设的带宽需求。

\section{特性}

GDMA-AHB 和 GDMA-AXI 具有以下共同特性：

\begin{itemize}
    \item 数据传输以字节为单位，传输数据量可软件编程
    \item 支持任意地址和大小 (size) 访问
    \item 支持链表
    \item 任一通道支持可配置的外设选择
    \item 支持通道间优先级和权重仲裁配置
    \item 支持存储器到存储器传输功能
\end{itemize}

GDMA-AHB 特性：

\begin{itemize}
    \item 架构：AHB 总线架构
    \item 通道：GDMA-AHB-HP 有五个发送通道和五个接收通道，GDMA-AHB-LP 有两个发送通道和两个接收通道
    \item 对齐要求：
        \begin{itemize}
            \item 描述符存储地址：字对齐
            \item 数据地址和长度：
                \begin{itemize}
                    \item 内部存储器和外部存储器的非加密空间：无要求
                    \item 外部存储器的加密空间（仅 GDMA-AHB-HP 支持访问，GDMA-AHB-LP 不支持）：16 字节对齐
                \end{itemize}
        \end{itemize}
    \item 访问存储器时支持 INCR4、INCR8 或 INCR16 突发传输
\end{itemize}

GDMA-AXI 特性：

\begin{itemize}
    \item 架构：AXI 总线架构，支持深度为 8 的乱序传输 (out-of-order) 和深度为 8 的挂起传输 (outstanding)
    \item 通道：各有三个发送通道和三个接收通道
    \item 对齐要求：
        \begin{itemize}
            \item 描述符存储地址：双字对齐
            \item 数据地址和长度：
                \begin{itemize}
                    \item 内部存储器和外部存储器的非加密空间：无要求
                    \item 外部存储器的加密空间：16 字节对齐
                \end{itemize}
        \end{itemize}
    \item 访问存储器时支持突发传输，突发长度可配置为 1、2、4、8、16 拍
    \item 支持软件切换链表中断响应机制
\end{itemize}


\section{架构}

GDMA 控制器与 CPU 的数据总线使用相同的地址空间访问存储器。\chipname{} 中所有需要高速数据传输的模块均支持 GDMA 功能。图 \ref{fig:gdma-controller} 为 GDMA 控制器基本架构图。

\begin{figure}[H]
\input{\modulefiles/figures/gdma_arch.tex}
\centering
\caption{GDMA 控制器架构}
\label{fig:gdma-controller}
\end{figure}

GDMA-AHB 和 GDMA-AXI 都有固定数量的传输通道，其发送通道和接收通道的数量一致。每个通道可选择与不同的外设相连，从而实现通道资源由外设共享。

GDMA-AHB 和 GDMA-AXI 通过 AHB 总线或 AXI 总线将数据存入内部或外部存储器，或者从内部或外部存储器取出数据。在通过总线传输数据之前，GDMA 采用可配置的仲裁机制对每个通道的读写请求进行仲裁。存储器的具体使用范围详见章节 \ref{mod:sysmem} \textit{\nameref{mod:sysmem}}。

软件可以通过挂载链表的方式来使用 GDMA 控制器。GDMA-AHB 链表存储在内部存储器中，GDMA-AXI 链表存储在内部或外部存储器中。这些链表包括 outlink\textcolor{red}{\it{n}} 与 inlink\textcolor{red}{\it{n}}，本文以 \textcolor{red}{\it{n}} 来表示通道号，\textcolor{red}{\it{n}} 为实际物理通道编号。

GDMA 从存储器中取得链表，然后根据 outlink\textcolor{red}{\it{n}} 中的内容将相应存储器中的数据发送出去，也可根据 inlink\textcolor{red}{\it{n}} 中的内容将接收的数据存入指定的存储器地址空间。


\section{功能描述}

\subsection{链表}

\begin{figure}[H]
\includegraphics[width=0.9\textwidth]{\modulefiles/figures/link_strut}
\centering
\caption{链表结构图}
\label{fig:gdma-link-descriptor}
\end{figure}

图 \ref{fig:gdma-link-descriptor} 所示为链表的结构图。发送链表与接收链表结构相同。每个链表由一个或多个描述符构成，每个描述符由三个字组成。链表应存放在存储器中，供 GDMA 控制器使用。描述符各字段的含义如下：

\begin{itemize}
    \item owner (DW0) [31]：表示当前描述符对应的 buffer 允许的操作者。\\
    0：允许的操作者为 CPU。\\
    1：允许的操作者为 GDMA 控制器。\\
    在 GDMA 使用完该描述符对应的 buffer 后，对于接收链表描述符，硬件默认会自动将该位清零；对于发送链表描述符，需要将 \hyperref[fielddesc:AHBDMAOUTAUTOWRBACKCHN]{AHB/AXI\_DMA\_OUT\_AUTO\_WRBACK\_CH\regindex{n}} 置 1，硬件才会自动将该位清零。软件也可通过置位 \hyperref[fielddesc:AHBDMAOUTLOOPTESTCHN]{AHB/AXI\_DMA\_OUT\_LOOP\_TEST\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAINLOOPTESTCHN]{AHB/AXI\_DMA\_IN\_LOOP\_TEST\_CH\regindex{n}} 来关闭硬件自动清零功能。软件在挂载链表时需要将该位置 1。

    {\bfseries 注意： } 本文以 AHB/AXI\_DMA\_OUT 开头的寄存器对应 TX 通道寄存器，以 AHB/AXI\_DMA\_IN 开头的寄存器对应 RX 通道寄存器。
    \item suc\_eof (DW0) [30]：表示一个描述符对应的数据成功传输后是否触发 AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT 或 AHB/AXI\_DMA\_OUT\_EOF\_CH\regindex{n}\_INT 中断。\\
    0：当前描述符成功传输后不会触发中断；\\
    1：当前描述符成功传输后触发中断。\\
    对于接收链表描述符，需要软件将该位写 0，硬件会在接收到包含 EOF 标志的数据后将该位置 1。\\对于发送链表描述符，需要软件按需要将描述符中的该位置 1。
    如果软件在某个描述符中将该位配置为 1，则 GDMA 在处理完该描述符时，会在发送给外设的数据中加入 EOF 标志，告知外设该段数据已阶段性结束。
    \item Reserved (DW0) [29]：保留。此位为无关项。
    \item err\_eof (DW0) [28]：表示接收结束错误标志。\\
    0：接收数据没有错误。\\
    1：接收数据有错误。\\
    该位只用于 UHCI 或 PARLIO 利用 GDMA 接收数据。对于接收链表描述符，硬件在收完描述符对应的数据段并检测到接收数据错误时，会将该位置 1。
    \item Reserved (DW0) [27:24]：保留。
    \item length (DW0) [23:12]：表示当前描述符对应的 buffer 中的有效字节数。对于发送链表描述符，该段由软件填写，表示从 buffer 中读取数据时需要读取的字节数。对于接收链表描述符，该段由硬件在使用完该 buffer 后或接收到最后一个数据时自动填写，表示 buffer 中存储的有效字节数。
    \item size (DW0) [11:0]：表示当前描述符对应的 buffer 容量的字节数。
    \item buffer address pointer (DW1)：buffer 的地址。
    \item next descriptor address (DW2)：下一个描述符的地址。如果当前描述符为链表中最后一个描述符，该值为 0。对于 GDMA-AHB，该地址必须指向内部存储器的地址空间；对于 GDMA-AXI，该地址必须指向内部或外部存储器的地址空间。
    \begin{tiplisting}
        GDMA-AHB 的链表描述符存储地址须 4 字节对齐，GDMA-AXI 须 8 字节对齐。
    \end{tiplisting}
\end{itemize}


用 GDMA 接收数据时，如果接收数据的长度小于当前描述符指定的 buffer size，则下一个描述符对应的接收数据不会占用该 buffer 的剩余空间。

\subsection{存储器到存储器数据传输}
GDMA 支持存储器到存储器的数据传输。置位 \hyperref[fielddesc:AHBDMAMEMTRANSENCHN]{AHB/AXI\_DMA\_MEM\_TRANS\_EN\_CH\regindex{n}} 后，TX 通道\textcolor{red}{\it{n}} 的输出将与 RX 通道\textcolor{red}{\it{n}} 的输入相连，从而启用存储器到存储器的数据传输功能。

一个 TX 通道仅与其编号对应的 RX 通道配对，实现存储器到存储器传输。同时，需要将 \hyperref[fielddesc:AHBDMAPERIINSELCHN]{AHB/AXI\_DMA\_PERI\_IN\_SEL\_CH\regindex{n}} 和 \hyperref[fielddesc:AHBDMAPERIOUTSELCHN]{AHB/AXI\_DMA\_PERI\_OUT\_SEL\_CH\regindex{n}} 配置为相同且对应 Dummy 的值。

GDMA-AHB-HP 的 5 个通道和 GDMA-AHB-LP 的 2 个通道均支持存储器到存储器的数据传输，\hyperref[fielddesc:AHBDMAAHBINFRESPERRID]{AHB\_DMA\_AHBINF\_RESP\_ERR\_ID} 记录到的 ID 为固定值：ID 为 16 时，指 GDMA-AHB 通道 0 的存储器到存储器传输；ID 为 17 时，指 GDMA-AHB 通道 1 的存储器到存储器传输，以此类推。

\subsection{启动 GDMA}

软件通过挂载链表的方式来使用 GDMA。对于接收数据，软件挂载好接收链表并准备好接收数据，配置 \hyperref[fielddesc:AHBDMAINLINKADDRCHN]{AHB/AXI\_DMA\_INLINK\_ADDR\_CH\regindex{n}} 字段指向第一个接收链表描述符，置位 \hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}} 位启动 GDMA。

对于发送数据，软件挂载好发送链表并准备好发送数据，配置 \hyperref[fielddesc:AHBDMAOUTLINKADDRCHN]{AHB/AXI\_DMA\_OUTLINK\_ADDR\_CH\regindex{n}} 字段指向第一个发送链表描述符，置位 \hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 位启动 GDMA。\hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}} 与 \hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 位由硬件自动清零。

对于 GDMA-AXI RX 通道，置位 \hyperref[fielddesc:AXIDMAINCMDDISABLECHN]{AXI\_DMA\_IN\_CMD\_DISABLE\_CH\regindex{n}} 可暂停对应通道的数据传输。

有时需要在 DMA 数据传输已经开始后追加更多描述符。要追加描述符，看似只需清空已挂载链表最后一个描述符的 EOF 位，并将该描述符的 next descriptor address (DW2) 字段配置为新链表第一个描述符的地址。但如果 DMA 数据传输已经或即将结束，该方法便无法奏效。GDMA 控制器有专门的逻辑来确保数据传输继续或重启：如果数据传输仍在进行，GDMA 控制器会处理新追加的描述符；如果数据传输已经结束，GDMA 控制器会重启数据传输，传输新追加的描述符。该逻辑由 Restart 功能实现。

软件使用 Restart 功能时，需要重写已挂载链表的最后一个描述符，使其第三个字（即 DW2）指向新链表的首地址；然后置位 \hyperref[fielddesc:AHBDMAINLINKRESTARTCHN]{AHB/AXI\_DMA\_INLINK\_RESTART\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAOUTLINKRESTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_RESTART\_CH\regindex{n}}（这两个位由硬件自动清零）。如图 \ref{fig:gdma-link-restart} 所示，硬件在读取已挂载链表的最后一个描述符时，会获取新挂载链表的地址，从而继续处理新挂载的链表。

\subsection{读链表}

软件在配置并启动 GDMA 后，GDMA 会从存储器读取链表，并检查读入的链表描述符是否正确。只有当链表描述符通过所有检查时，GDMA 对应的通道才会开始传输数据。链表描述符未通过检查时，硬件将触发描述符错误中断（AHB/AXI\_DMA\_IN\_DSCR\_ERR\_CH\regindex{n}\_INT 或 AHB/AXI\_DMA\_OUT\_DSCR\_ERR\_CH\regindex{n}\_INT），同时该通道将处于阻塞状态并停止工作。

描述符检查项包括：
\begin{itemize}
    \item \hyperref[fielddesc:AHBDMAINCHECKOWNERCHN]{AHB/AXI\_DMA\_IN\_CHECK\_OWNER\_CH\regindex{n}} 或者 \hyperref[fielddesc:AHBDMAOUTCHECKOWNERCHN]{AHB/AXI\_DMA\_OUT\_CHECK\_OWNER\_CH\regindex{n}} 置 1 时，检查描述符的 owner 位。如果该位为 0，表示当前操作者为 CPU，则不通过检查。\hyperref[fielddesc:AHBDMAINCHECKOWNERCHN]{AHB/AXI\_DMA\_IN\_CHECK\_OWNER\_CH\regindex{n}} 或者 \hyperref[fielddesc:AHBDMAOUTCHECKOWNERCHN]{AHB/AXI\_DMA\_OUT\_CHECK\_OWNER\_CH\regindex{n}} 置 0 时，不检查描述符的 owner 位。\\

    \item 检查描述符本身的存储地址是否在配置的存储器地址空间内。
        \begin{itemize}
            \item GDMA-AHB：描述符地址须在 \hyperref[fielddesc:AHBDMAACCESSINTRMEMSTARTADDR]{AHB\_DMA\_ACCESS\_INTR\_MEM\_START\_ADDR} \verb+~+ \hyperref[fielddesc:AHBDMAACCESSINTRMEMENDADDR]{AHB\_DMA\_ACCESS\_INTR\_MEM\_END\_ADDR} 值的范围内。
            \item GDMA-AXI：描述符地址须在 \hyperref[fielddesc:AXIDMAACCESSINTRMEMSTARTADDR]{AXI\_DMA\_ACCESS\_INTR\_MEM\_START\_ADDR} \verb+~+ \hyperref[fielddesc:AXIDMAACCESSINTRMEMENDADDR]{AXI\_DMA\_ACCESS\_INTR\_MEM\_END\_ADDR}，或 \hyperref[fielddesc:AXIDMAACCESSEXTRMEMSTARTADDR]{AXI\_DMA\_ACCESS\_EXTR\_MEM\_START\_ADDR} \verb+~+ \hyperref[fielddesc:AXIDMAACCESSEXTRMEMENDADDR]{AXI\_DMA\_ACCESS\_EXTR\_MEM\_END\_ADDR} 值的范围内。
        \end{itemize}
        请参见章节 \ref{sec:dma-access-inter-ram}。\\
\end{itemize}

软件在检测到通道描述符错误中断后，需要复位对应的通道，并置位 \hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}} 位以重新启动 GDMA。


\subsection{GDMA-AXI 切换链表的中断响应机制}

GDMA-AXI 支持在链表切换完成时触发中断。软件可将 \hyperref[fielddesc:AXIDMALINKSWITCHSTATECHN]{AXI\_DMA\_LINK\_SWITCH\_STATE\_CH\regindex{n}} 配置为 1，使能 GDMA-AXI 切换链表。链表切换成功后，如果 AXI\_DMA\_OUT\_LINK\_SWITCH\_CH\regindex{n}\_INT 已使能，GDMA-AXI 会产生该中断，并将 \hyperref[fielddesc:AXIDMALINKSWITCHSTATECHN]{AXI\_DMA\_LINK\_SWITCH\_STATE\_CH\regindex{n}} 清零，表示链表已完成切换。

该功能仅用于状态指示，不影响 GDMA-AXI 的正常传输。

\subsection{数据传输结束标志}

{\bfseries 注意：} 本章中发送链表描述符的 EOF 指描述符第一个字中的 bit 30 所指示的 suc\_eof；接收链表描述符的 EOF 可以是 bit 30 指示的 suc\_eof，或 bit 28 指示的 err\_eof。

GDMA 通过 EOF 指示对应描述符的数据段传输已完成。

发送数据时，产生 EOF 和 TOTAL EOF 两种中断：
\begin{itemize}
    \item AHB/AXI\_DMA\_OUT\_EOF\_CH\regindex{n}\_INT：链表中的任意一个描述符配置了 suc\_eof 标志位时，该描述符对应的数据传输完成后，GDMA 都会产生 EOF 中断。置位 \hyperref[fielddesc:AHBDMAOUTEOFCHNINTENA]{AHB/AXI\_DMA\_OUT\_EOF\_CH\regindex{n}\_INT\_ENA} 位使能该中断。
    \item AHB/AXI\_DMA\_OUT\_TOTAL\_EOF\_CH\regindex{n}\_INT：如果该链表中的最后一个描述符配置了 suc\_eof 标志位，则当该链表的最后一个描述符对应的数据传输完成后，GDMA 会产生 TOTAL EOF 中断。置位 \hyperref[fielddesc:AHBDMAOUTTOTALEOFCHNINTENA]{AHB/AXI\_DMA\_OUT\_TOTAL\_EOF\_CH\regindex{n}\_INT\_ENA} 位使能该中断。
\end{itemize}


接收数据时，可产生以下中断：
\begin{itemize}
    \item AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT：表示带有 EOF 标志的数据段接收完成。置位 \hyperref[fielddesc:AHBDMAINSUCEOFCHNINTENA]{AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT\_ENA} 位使能该中断。
    \item（仅 UHCI 和 PARLIO）AHB/AXI\_DMA\_IN\_ERR\_EOF\_CH\regindex{n}\_INT：表示对应描述符所需传输的数据段接收完成但接收数据有错误。置位 \hyperref[fielddesc:AHBDMAINERREOFCHNINTENA]{AHB/AXI\_DMA\_IN\_ERR\_EOF\_CH\regindex{n}\_INT\_ENA} 使能该中断。该中断仅在通道连接的外设为 UHCI 或 PARLIO 时有效。
\end{itemize}


软件在检测到 \hyperref[int:GDMAOUTTOTALEOFINT]{AHB/AXI\_DMA\_OUT\_TOTAL\_EOF\_CH\regindex{n}\_INT} 或 \hyperref[int:GDMAINSUCEOFINT]{AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT} 中断时，可通过读取 \hyperref[fielddesc:AHBDMAOUTEOFDESADDRCHN]{AHB/AXI\_DMA\_OUT\_EOF\_DES\_ADDR\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAINSUCEOFDESADDRCHN]{AHB/AXI\_DMA\_IN\_SUC\_EOF\_DES\_ADDR\_CH\regindex{n}} 字段的值，获取当前已完成数据传输的描述符存储地址。这样，软件可以知道哪些描述符已被使用，并根据需要回收描述符。

RX 方向还支持记录 \hyperref[int:GDMAINERREOFINT]{AHB/AXI\_DMA\_IN\_ERR\_EOF\_CH\regindex{n}\_INT} 中断触发时描述符的存储地址，可通过 \hyperref[fielddesc:AHBDMAINERREOFDESADDRCHN]{AHB/AXI\_DMA\_IN\_ERR\_EOF\_DES\_ADDR\_CH\regindex{n}} 字段获取。

置位 \hyperref[fielddesc:AHBDMAINLINKAUTORETCHN]{AHB/AXI\_DMA\_INLINK\_AUTO\_RET\_CH\regindex{n}} 后，当外设向 GDMA 推送带有 err\_eof 标志的数据时，GDMA 会返回到当前帧的起始描述符地址，并重新执行该帧的接收传输。

\subsection{访问存储器}\label{sec:dma-access-inter-ram}
GDMA-AHB 的 RX/TX 通道可访问内部和外部存储器。可访问的地址空间由寄存器 \hyperref[fielddesc:AHBDMAACCESSINTRMEMSTARTADDR]{AHB\_DMA\_ACCESS\_INTR\_MEM\_START\_ADDR} \verb+~+ \hyperref[fielddesc:AHBDMAACCESSINTRMEMENDADDR]{AHB\_DMA\_ACCESS\_INTR\_MEM\_END\_ADDR} 的配置值决定。

GDMA-AXI 的 RX/TX 通道可访问：
\begin{itemize}
    \item \hyperref[fielddesc:AXIDMAACCESSINTRMEMSTARTADDR]{AXI\_DMA\_ACCESS\_INTR\_MEM\_START\_ADDR} 和 \hyperref[fielddesc:AXIDMAACCESSINTRMEMENDADDR]{AXI\_DMA\_ACCESS\_INTR\_MEM\_END\_ADDR} 配置的内部存储器区间；
    \item \hyperref[fielddesc:AXIDMAACCESSEXTRMEMSTARTADDR]{AXI\_DMA\_ACCESS\_EXTR\_MEM\_START\_ADDR} 和 \hyperref[fielddesc:AXIDMAACCESSEXTRMEMENDADDR]{AXI\_DMA\_ACCESS\_EXTR\_MEM\_END\_ADDR} 配置的外部存储器区间。
\end{itemize}

为加速数据传输，GDMA 支持突发传输模式。GDMA-AHB 默认不使能突发传输模式，可通过置位 \hyperref[fielddesc:AHBDMAINDSCRBURSTENCHN]{AHB\_DMA\_INDSCR\_BURST\_EN\_CH\regindex{n}} 使能 RX 通道描述符突发传输模式，置位 \hyperref[fielddesc:AHBDMAOUTDSCRBURSTENCHN]{AHB\_DMA\_OUTDSCR\_BURST\_EN\_CH\regindex{n}} 使能 TX 通道描述符突发传输模式。配置\hyperref[fielddesc:AHBDMAINDATABURSTMODESELCHN]{AHB\_DMA\_IN\_DATA\_BURST\_MODE\_SEL\_CH\regindex{n}}选择 RX 通道数据突发传输模式，配置 \hyperref[fielddesc:AHBDMAOUTDATABURSTMODESELCHN]{AHB\_DMA\_OUT\_DATA\_BURST\_MODE\_SEL\_CH\regindex{n}}选择 TX 通道数据突发传输模式。突发传输模式可选如下：
\begin{itemize}
    \item 0：SINGLE 传输（4 字节）
    \item 1：INCR4 传输（16 字节）
    \item 2：INCR8 传输（32 字节）
    \item 3：INCR16 传输 （64 字节）
\end{itemize}

GDMA-AXI 突发传输模式默认打开且无法关闭。用户可通过 \hyperref[fielddesc:AXIDMAINBURSTSIZESELCHN]{AXI\_DMA\_IN\_BURST\_SIZE\_SEL\_CH\regindex{n}} 和 \hyperref[fielddesc:AXIDMAOUTBURSTSIZESELCHN]{AXI\_DMA\_OUT\_BURST\_SIZE\_SEL\_CH\regindex{n}} 控制 AXI 总线突发传输的数据量，将突发传输长度配置为 8、16、32、64 或 128 字节。

GDMA-AHB 和 GDMA-AXI 访问配置的内部存储器和外部存储器的非加密空间时，链表描述符参数无对齐要求。

访问外部存储器的加密空间（详见章节 \ref{mod:extmemencr} \textit{\nameref{mod:extmemencr}}）时，buffer address pointer 和对应数据需按 16 字节对齐，其他参数无要求。

GDMA-AHB-LP 无法访问外部存储器的加密空间。


\subsection{仲裁}

为了确保及时响应 SPI 等高速低延迟外设的请求，GDMA 引入通道优先级仲裁和通道权重仲裁两种仲裁机制。
\begin{itemize}
\item 优先级仲裁方式：GDMA 支持 16（0 \verb+~+ 15）个等级的优先级，数字越大优先级越高。若多个通道在同一时刻存在数据传输需求，GDMA 会按照通道优先级从高到低顺序响应各通道的数据传输请求。
\item 权重仲裁方式：
    \begin{itemize}
        \item 每个通道的权重（即令牌数）可配置为 0 \verb+~+ 15 之间的任意值。GDMA 按一定的总线 (AHB/AXI) 时钟周期长度划分时间片。在每个时间片内，各通道的数据传输请求次数按所配置的令牌数分配：通道每发起一次数据传输请求即消耗一个令牌。

        若通道在某个时间片内耗尽令牌，则该通道的请求将不再被响应，直到仲裁时间达到时间片规定长度，或所有通道的令牌均已耗尽。此时将刷新令牌数，进入下一个时间片。
        \item 若通道令牌数配置为非零值，即使无数据传输请求，也会在每个时间片内等待所有通道的令牌耗尽，不会提前退出当前仲裁时间片。通道无数据传输请求且令牌值非 0 时，会造成一定的带宽浪费。

        为此，GDMA 提供权重仲裁优化开关。启用权重仲裁优化后，若通道无数据传输需求，则该通道的令牌数视为 0，不再参与仲裁。当所有通道均无数据传输请求时，仲裁器提前退出当前时间片，从而提高仲裁响应速度和传输速率。
    \end{itemize}
\end{itemize}
无论通道优先级怎么配置，描述符传输的优先级一定高于数据传输的优先级。但描述符传输仍然会受到权重配置的限制，当配置的令牌耗尽，只有进入下一个时间片才能继续申请仲裁。
\begin{tiplisting}
\vspace{-2em}
\begin{itemize}
    \item 若同时配置优先级仲裁和通道权重仲裁，且优先级不同、权重相同，则在各通道传输相同且较少的数据量时，优先级高的通道优先完成传输。
    \item 若优先级和权重均不同，且各通道传输的数据量相同且较大，则权重较大的通道能优先分配到更大带宽，从而优先完成传输。
\end{itemize}
\end{tiplisting}


\subsection{总线错误响应信息记录}\label{sec:dma-bus-error-resp}

在 GDMA-AHB 传输数据期间，如果总线上从机侧回复了错误响应 (Error Response)，数据传输不会中断，GDMA-AHB 仍会按已有链表继续传输数据。这可能导致数据传输完成后，实际得到的数据与预期不符。为便于定位问题，GDMA-AHB 在传输数据过程中若发生错误响应，可通过以下内部寄存器记录相关传输信息：

\begin{itemize}
    \item \hyperref[fielddesc:AHBDMAAHBINFRESPERRADDR]{AHB\_DMA\_AHBINF\_RESP\_ERR\_ADDR}：记录本次总线传输对应的 32 位地址。
    \item \hyperref[fielddesc:AHBDMAAHBINFRESPERRCHID]{AHB\_DMA\_AHBINF\_RESP\_ERR\_CH\_ID}：记录本次总线传输使用的 GDMA-AHB 通道。
    \item \hyperref[fielddesc:AHBDMAAHBINFRESPERRID]{AHB\_DMA\_AHBINF\_RESP\_ERR\_ID}：记录本次总线上外设与存储器传输或存储器与存储器传输的传输 ID。
    \item \hyperref[fielddesc:AHBDMAAHBINFRESPERRWR]{AHB\_DMA\_AHBINF\_RESP\_ERR\_WR}：记录本次总线传输对应的传输类型。
\end{itemize}

GDMA-AHB 作为主机发起 AHB 总线传输且收到错误响应时，还会产生错误响应中断以提醒 CPU。中断产生后，GDMA-AHB 仍不会中断数据传输。

此外，GDMA-AHB 不会锁存第一笔发生错误响应的 AHB 总线传输相关寄存器信息。若连续发生多笔错误响应传输，上述错误响应记录寄存器的内容会实时更新，最终寄存器中保留的是查询寄存器之前最后一笔发生错误响应的 AHB 总线传输信息。

\subsection{自动时钟门控}\label{sec:dma-auto-clk-gating}

GDMA-AHB 在工作时，某些场景只需要用到部分通道，此时可关闭未使用通道的时钟来降低功耗。同理，内部仲裁和总线接口模块仅在有数据传输时才需要工作，在空闲时也可以通过关闭时钟来降低功耗。目前 GDMA-AHB 内部有以下模块：
\begin{itemize}
    \item 总线接口处理模块
    \item 仲裁模块
    \item RX 数据处理模块
    \item RX 描述符处理模块
    \item TX 数据处理模块
    \item TX 描述符处理模块
    \item 寄存器配置同步模块
\end{itemize}

这些模块可在空闲时自动关闭模块时钟，以最大限度降低功耗，也支持通过寄存器配置强制保持时钟开启。例如，置位 \hyperref[fielddesc:AHBDMAAHBINFCLKEN]{AHB\_DMA\_AHBINF\_CLK\_EN} 可使总线接口处理模块时钟保持常开，其余模块时钟常开配置与其类似。

\section{事件任务矩阵功能} \label{sec:dma-etm-func}

在 \chipname{} 中，GDMA 支持 ETM 功能，即可通过任意外设的 ETM 事件触发 GDMA 的 ETM 任务，或通过 GDMA 的 ETM 事件触发任意外设的 ETM 任务。有关 ETM 的更多详细信息，请参考章节 \ref{mod:evntaskmatrix} \nameref{mod:evntaskmatrix}。本节仅介绍与 GDMA 相关的 ETM 任务和 ETM 事件。


GDMA 可接收的 ETM 任务有：

\begin{itemize}
\item GDMA\_AHB/AXI\_TASK\_IN\_START\_CH\regindex{n}：触发时开启 GDMA 的接收通道 \regindex{n} 进行数据传输。
\item GDMA\_AHB/AXI\_TASK\_OUT\_START\_CH\regindex{n}：触发时开启 GDMA 的发送通道 \regindex{n} 进行数据传输。
\end{itemize}

\begin{tiplisting}
以上两个 ETM 任务与 CPU 配置 \hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}}、\hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 实现的功能相同。

\hyperref[fielddesc:AHBDMAINETMENCHN]{AHB/AXI\_DMA\_IN\_ETM\_EN\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAOUTETMENCHN]{AHB/AXI\_DMA\_OUT\_ETM\_EN\_CH\regindex{n}} 为 1 时，只有 ETM 可以启动对应方向及对应通道的 GDMA。\hyperref[fielddesc:AHBDMAINETMENCHN]{AHB/AXI\_DMA\_IN\_ETM\_EN\_CH\regindex{n}} 或 \hyperref[fielddesc:AHBDMAOUTETMENCHN]{AHB/AXI\_DMA\_OUT\_ETM\_EN\_CH\regindex{n}} 为 0 时，仅可通过 CPU 使能对应的 GDMA。
\end{tiplisting}

GDMA 可产生的 ETM 事件有：

\begin{itemize}
\item GDMA\_AHB/AXI\_EVT\_IN\_DONE\_CH\regindex{n}：表示通道 \regindex{n} 接收方向链表描述符指向的数据接收完成。
\item GDMA\_AHB/AXI\_EVT\_IN\_SUC\_EOF\_CH\regindex{n}：通道 \regindex{n} 接收方向 EOF 位为 1 的链表描述符指向的数据接收完成指示。
\item GDMA\_AHB/AXI\_EVT\_IN\_FIFO\_EMPTY\_CH\regindex{n}：通道 \regindex{n} 接收方向 FIFO 非空到空状态改变指示。
\item GDMA\_AHB/AXI\_EVT\_IN\_FIFO\_FULL\_CH\regindex{n}：通道 \regindex{n} 接收方向 FIFO 非满到满状态改变指示。
\item GDMA\_AHB/AXI\_EVT\_OUT\_DONE\_CH\regindex{n}：通道 \regindex{n} 发送方向链表描述符指向的数据发送完成。
\item GDMA\_AHB/AXI\_EVT\_OUT\_SUC\_EOF\_CH\regindex{n}：通道 \regindex{n} 发送方向 EOF 位为 1 的链表描述符指向的数据发送完成指示。
\item GDMA\_AHB/AXI\_EVT\_OUT\_TOTAL\_EOF\_CH\regindex{n}：通道 \regindex{n} 发送方向最后一个且 EOF 位为 1 的链表描述符指向的数据发送完成指示。
\item GDMA\_AHB/AXI\_EVT\_OUT\_FIFO\_EMPTY\_CH\regindex{n}：通道 \regindex{n} 发送方向 FIFO 非空到空状态改变指示。
\item GDMA\_AHB/AXI\_EVT\_OUT\_FIFO\_FULL\_CH\regindex{n}：通道 \regindex{n} 发送方向 FIFO 非满到满状态改变指示。
\end{itemize}

在具体应用中，GDMA 的 ETM 事件可用来触发 GDMA 的 ETM 任务。例如，GDMA\_AHB/AXI\_EVT\_OUT\_TOTAL\_EOF\_CH0 事件可触发 GDMA\_AHB/AXI\_TASK\_IN\_START\_CH1 任务，从而启动新一轮的 GDMA 操作。


\section{中断}

\chipname{} 的 GDMA 可以生成以下中断信号并发送给\hyperref[mod:intmtrx]{中断矩阵}。
    \begin{itemize}
        \item GDMA-AHB-HP:
            \begin{itemize}
                \item AHB\_PDMA\_IN/OUT\_CH0\_INTR
                \item AHB\_PDMA\_IN/OUT\_CH1\_INTR
                \item AHB\_PDMA\_IN/OUT\_CH2\_INTR
                \item AHB\_PDMA\_IN/OUT\_CH3\_INTR
                \item AHB\_PDMA\_IN/OUT\_CH4\_INTR
            \end{itemize}
        \item GDMA-AHB-LP:
            \begin{itemize}
                \item AHB\_PDMA\_IN/OUT\_CH0\_INTR
                \item AHB\_PDMA\_IN/OUT\_CH1\_INTR
            \end{itemize}
        \item GDMA-AXI:
            \begin{itemize}
                \item AXI\_PDMA\_IN/OUT\_CH0\_INTR
                \item AXI\_PDMA\_IN/OUT\_CH1\_INTR
                \item AXI\_PDMA\_IN/OUT\_CH2\_INTR
            \end{itemize}
    \end{itemize}

这些中断信号由 GDMA 的内部中断源生成。

以下中断源生成 AHB/AXI\_PDMA\_IN\_CH\regindex{n}\_INTR 中断信号：

\begin{itemize}
    \item \label{int:GDMAINDONEINT}AHB/AXI\_DMA\_IN\_DONE\_CH\regindex{n}\_INT：对于接收通道\textcolor{red}{\it{n}}，当一个接收链表描述符对应的数据接收完成时触发此中断。
    \item \label{int:GDMAINSUCEOFINT}AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT：对于接收通道\regindex{n}，当一个接收链表描述符对应的数据接收完成，并且描述符的 suc\_eof 为 1 时触发此中断。
    \item \label{int:GDMAINERREOFINT}AHB/AXI\_DMA\_IN\_ERR\_EOF\_CH\regindex{n}\_INT：对于接收通道\textcolor{red}{\it{n}}，当接收的描述符对应数据段中有错误发生时触发此中断。（该中断只用于外设选择 UHCI 或 PARLIO 时）。
    \item \label{int:GDMAINDSCREMPTYINT}AHB/AXI\_DMA\_IN\_DSCR\_EMPTY\_CH\regindex{n}\_INT：对于接收通道\textcolor{red}{\it{n}}，当接收链表描述符指向的 buffer size 小于待接收数据长度时触发此中断。
    \item \label{int:GDMAINDSCRERRINT}AHB/AXI\_DMA\_IN\_DSCR\_ERR\_CH\regindex{n}\_INT：对于接收通道\textcolor{red}{\it{n}}，当接收链表描述符未通过任一描述符检查时触发此中断。
    \item \label{int:GDMAINFIFOOVFINT} AHB\_DMA\_INFIFO\_OVF\_CH\regindex{n}\_INT 或 AXI\_DMA\_INFIFO\_L1/L2/L3\_OVF\_CH\regindex{n}\_INT：GDMA-AHB 接收数据方向缓存或 GDMA-AXI 接收数据方向 L1、L2、L3 缓存溢出时触发此中断。
    \item \label{int:GDMAINFIFOUDFINT}AHB/AXI\_DMA\_INFIFO\_UDF\_CH\regindex{n}\_INT 或 AXI\_DMA\_INFIFO\_L1/L2/L3\_UDF\_CH\regindex{n}\_INT：GDMA-AHB 接收数据方向缓存或 GDMA-AXI 接收数据方向 L1、L2、L3 缓存无数据时触发此中断。
    \item \label{int:GDMAINAHBINFRESPERRINT}AHB\_DMA\_IN\_AHBINF\_RESP\_ERR\_CH\regindex{n}\_INT：GDMA-AHB 接收通道\textcolor{red}{\it{n}} 进行数据传输时，若 AHB 总线上发生错误响应，触发此中断。
\end{itemize}

以下中断源生成 AHB/AXI\_PDMA\_OUT\_CH\regindex{n}\_INTR 中断信号：

\begin{itemize}
    \item \label{int:GDMAOUTDONEINT}AHB/AXI\_DMA\_OUT\_DONE\_CH\regindex{n}\_INT：对于发送通道\textcolor{red}{\it{n}}，当一个发送链表描述符对应的数据发送完成时触发此中断。
    \item \label{int:GDMAOUTEOFINT}AHB/AXI\_DMA\_OUT\_EOF\_CH\regindex{n}\_INT：对于发送通道\textcolor{red}{\it{n}}，当发送链表描述符的 EOF 位为 1 时触发此中断。触发时机取决于 \hyperref[fielddesc:AHBDMAOUTEOFMODECHN]{AHB/AXI\_DMA\_OUT\_EOF\_MODE\_CH\regindex{n}} 的配置：
        \begin{itemize}
            \item 为 0 时：该描述符对应的最后一个数据由总线传入 GDMA TX 通道时触发；
            \item 为 1 时：该描述符对应的最后一个数据从 GDMA TX 通道发出时触发。
        \end{itemize}
    \item \label{int:GDMAOUTDSCRERRINT}AHB/AXI\_DMA\_OUT\_DSCR\_ERR\_CH\regindex{n}\_INT：对于发送通道\textcolor{red}{\it{n}}，当发送链表描述符未通过任一描述符检查时会触发此中断。
    \item \label{int:GDMAOUTTOTALEOFINT}AHB/AXI\_DMA\_OUT\_TOTAL\_EOF\_CH\regindex{n}\_INT：对于发送通道\textcolor{red}{\it{n}}，当链表中最后一个描述符配置了 suc\_eof 且该描述符对应的数据传输完成后触发此中断。
    \item \label{int:GDMAOUTFIFOOVFINT} AHB\_DMA\_OUTFIFO\_OVF\_CH\regindex{n}\_INT 或 AXI\_DMA\_OUTFIFO\_L1/L2/L3\_OVF\_CH\regindex{n}\_INT：GDMA-AHB 发送数据方向缓存或 GDMA-AXI 发送数据方向 L1、L2、L3 缓存溢出时触发此中断。
    \item \label{int:GDMAOUTFIFOUDFINT}AHB\_DMA\_OUTFIFO\_UDF\_CH\regindex{n}\_INT 或 AXI\_DMA\_OUTFIFO\_L1/L2/L3\_UDF\_CH\regindex{n}\_INT：GDMA-AHB 发送数据方向缓存或 GDMA-AXI 发送数据方向 L1、L2、L3 缓存无数据时触发此中断。
    \item \label{int:AXIDMAOUTLINKSWITCHINT}AXI\_DMA\_OUT\_LINK\_SWITCH\_CH\regindex{n}\_INT：GDMA-AXI 发送通道 \regindex{n} 从一个链表切换到下一个链表时触发此中断。
    \item  \label{int:GDMAOUTAHBINFRESPERRINT}AHB\_DMA\_OUT\_AHBINF\_RESP\_ERR\_CH\regindex{n}\_INT：GDMA-AHB 发送通道\textcolor{red}{\it{n}} 进行数据传输时，若 AHB 总线上发生错误响应，触发此中断。
\end{itemize}


\section{编程流程}

可通过配置 \hyperref[fielddesc:HPSYSCLKRSTAHBPDMASYSCLKEN]{HP\_SYS\_CLKRST\_AHB/AXI\_PDMA\_SYS\_CLK\_EN} 寄存器管理 GDMA 时钟门控，默认时钟门控打开。可通过配置 \hyperref[fielddesc:HPSYSCLKRSTRSTENAHBPDMA]{HP\_SYS\_CLKRST\_RST\_EN\_AHB/AXI\_PDMA} 对 GDMA 模块全局复位。

\subsection{GDMA TX 通道配置流程}
利用 GDMA 发送数据时，GDMA TX 通道的软件配置流程如下：
\begin{enumerate}
    \item 对寄存器 \hyperref[fielddesc:AHBDMAOUTRSTCHN]{AHB/AXI\_DMA\_OUT\_RST\_CH\regindex{n}} 置 1 然后置 0，复位 GDMA TX 通道状态机和 FIFO 指针；
    \item 挂载好发送链表，配置寄存器 \hyperref[fielddesc:AHBDMAOUTLINKADDRCHN]{AHB/AXI\_DMA\_OUTLINK\_ADDR\_CH\regindex{n}} 指向第一个发送链表描述符；
    \item 配置 \hyperref[fielddesc:AHBDMAPERIOUTSELCHN]{AHB/AXI\_DMA\_PERI\_OUT\_SEL\_CH\regindex{n}} 为对应的外设号，见表 \ref{tab:gdma-ahb-hp-peri-sel}、\ref{tab:gdma-ahb-lp-peri-sel} 和 \ref{tab:gdma-axi-peri-sel}；
    \item 置位 \hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 启动 GDMA TX 通道发送数据；
    \item 配置对应的外设，并启动该外设，具体配置请参考对应的外设章节；
    \item 等待 AHB/AXI\_DMA\_OUT\_TOTAL\_EOF\_CH\regindex{n}\_INT 中断，即数据传输完成。
\end{enumerate}

\subsection{GDMA RX 通道配置流程}
利用 GDMA 接收数据时，GDMA RX 通道的软件配置流程如下：
\begin{enumerate}
    \item 对寄存器 \hyperref[fielddesc:AHBDMAINRSTCHN]{AHB/AXI\_DMA\_IN\_RST\_CH\regindex{n}} 置 1 然后置 0，复位 GDMA RX 通道状态机和 FIFO 指针；
    \item 挂载好接收链表，配置寄存器 \hyperref[fielddesc:AHBDMAINLINKADDRCHN]{AHB/AXI\_DMA\_INLINK\_ADDR\_CH\regindex{n}} 指向第一个接收链表描述符；
    \item 配置 \hyperref[fielddesc:AHBDMAPERIINSELCHN]{AHB/AXI\_DMA\_PERI\_IN\_SEL\_CH\regindex{n}} 为对应的外设号，见表 \ref{tab:gdma-ahb-hp-peri-sel}、\ref{tab:gdma-ahb-lp-peri-sel} 和 \ref{tab:gdma-axi-peri-sel}；
    \item 置位 \hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}} 启动 GDMA RX 通道接收数据；
    \item 配置对应的外设，并启动该外设，具体配置请参考对应的外设章节。
\end{enumerate}

\subsection{GDMA 存储器到存储器配置流程}
利用 GDMA 进行存储器到存储器数据传输时，配置流程如下：
\begin{enumerate}
    \item 对寄存器 \hyperref[fielddesc:AHBDMAOUTRSTCHN]{AHB/AXI\_DMA\_OUT\_RST\_CH\regindex{n}} 置 1 然后置 0，复位 GDMA TX 通道状态机和 FIFO 指针；
    \item 对寄存器 \hyperref[fielddesc:AHBDMAINRSTCHN]{AHB/AXI\_DMA\_IN\_RST\_CH\regindex{n}} 置 1 然后置 0，复位 GDMA RX 通道状态机和 FIFO 指针；
    \item 挂载好发送链表，配置寄存器 \hyperref[fielddesc:AHBDMAOUTLINKADDRCHN]{AHB/AXI\_DMA\_OUTLINK\_ADDR\_CH\regindex{n}} 指向第一个发送链表描述符；
    \item 挂载好接收链表，配置寄存器 \hyperref[fielddesc:AHBDMAINLINKADDRCHN]{AHB/AXI\_DMA\_INLINK\_ADDR\_CH\regindex{n}} 指向第一个接收链表描述符；
    \item 置位 \hyperref[fielddesc:AHBDMAMEMTRANSENCHN]{AHB/AXI\_DMA\_MEM\_TRANS\_EN\_CH\regindex{n}} 使能存储器到存储器传输功能；
    \item 置位 \hyperref[fielddesc:AHBDMAOUTLINKSTARTCHN]{AHB/AXI\_DMA\_OUTLINK\_START\_CH\regindex{n}} 启动 GDMA TX 通道发送数据；
    \item 置位 \hyperref[fielddesc:AHBDMAINLINKSTARTCHN]{AHB/AXI\_DMA\_INLINK\_START\_CH\regindex{n}} 启动 GDMA RX 通道接收数据；
    \item 如果某个发送链表描述符的 suc\_eof 位配置为 1，则该描述符对应的数据段传输结束后会触发 AHB/AXI\_DMA\_IN\_SUC\_EOF\_CH\regindex{n}\_INT 中断。
\end{enumerate}

\subsection{通道优先级和权重配置流程}

优先级仲裁配置方法如下：
\begin{enumerate}
\item  配置 \hyperref[fielddesc:AHBDMATXPRICHN]{AHB/AXI\_DMA\_TX\_PRI\_CH\regindex{n}} 和 \hyperref[fielddesc:AHBDMARXPRICHN]{AHB/AXI\_DMA\_RX\_PRI\_CH\regindex{n}} 为 TX 和 RX 通道的优先级。
\end{enumerate}

权重仲裁配置方法如下:
\begin{enumerate}
\item 配置权重仲裁的时间片长度：
    \begin{itemize}
        \item GDMA-AHB：配置 \hyperref[fielddesc:AHBDMAARBTIMEOUT]{AHB\_DMA\_ARB\_TIMEOUT}，同时适用于 TX 和 RX 方向；
        \item GDMA-AXI：TX 和 RX 方向通过 \hyperref[fielddesc:AXIDMAARBTIMEOUTTX]{AXI\_DMA\_ARB\_TIMEOUT\_TX} 和 \hyperref[fielddesc:AXIDMAARBTIMEOUTRX]{AXI\_DMA\_ARB\_TIMEOUT\_RX} 独立配置；
    \end{itemize}
\item 配置 \hyperref[fielddesc:AHBDMATXCHARBWEIGHCHN]{AHB/AXI\_DMA\_TX\_CH\_ARB\_WEIGH\_CH\regindex{n}} 和 \hyperref[fielddesc:AHBDMARXCHARBWEIGHCHN]{AHB/AXI\_DMA\_RX\_CH\_ARB\_WEIGH\_CH\regindex{n}} 为各个通道的令牌值；
\item 清除 \hyperref[fielddesc:AHBDMATXARBWEIGHOPTDIRCHN]{AHB/AXI\_DMA\_TX\_ARB\_WEIGH\_OPT\_DIR\_CH\regindex{n}} 和 \hyperref[fielddesc:AHBDMARXARBWEIGHOPTDIRCHN]{AHB/AXI\_DMA\_RX\_ARB\_WEIGH\_OPT\_DIR\_CH\regindex{n}}，使能 TX 和 RX 方向的权重仲裁优化；
\item 使能权重仲裁：
    \begin{itemize}
        \item GDMA-AHB：置位同一字段 \hyperref[fielddesc:AHBDMAWEIGHTEN]{AHB\_DMA\_WEIGHT\_EN}，同时使能 TX 和 RX 方向；
        \item GDMA-AXI：分别置位 \hyperref[fielddesc:AXIDMAWEIGHTENTX]{AXI\_DMA\_WEIGHT\_EN\_TX} 和 \hyperref[fielddesc:AXIDMAWEIGHTENRX]{AXI\_DMA\_WEIGHT\_EN\_RX}，使能 TX 和 RX 方向；
    \end{itemize}
\end{enumerate}
