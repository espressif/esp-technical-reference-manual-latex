\section{概述}


\chipname{} 芯片集成了一个模拟电压比较器，通过比较输入电压与参考电压来监测电压变化。比较器提供多个芯片焊盘 (PAD) 用于接入电压信号，支持多通道比较。比较结果可生成 ETM（事件任务矩阵）事件或触发中断。


%%%%%%%%%%%%%%%%%%%%
%%% Feature List %%%
%%%%%%%%%%%%%%%%%%%%

\section{主要特性}
\label{sec:anacom-features}

模拟电压比较器具有以下主要特性：

\begin{itemize}
    \item 提供 4 个芯片焊盘 (PAD) 接口，用于接入电压信号
    \item 支持内部或外部参考电压，内部参考电压支持迟滞功能
    \item 支持多通道电压比较：
    \begin{itemize}
        \item 最多支持 3 个通道
        \item 通过轮询扫描方式依次比较不同 PAD 的输入电压与参考电压
        \item 扫描可由软件启动或由 ETM 任务触发
    \end{itemize}
    \item 每个通道提供以下功能：
    \begin{itemize}
        \item 毛刺过滤
        \item 状态变化可产生 ETM 事件或触发中断
        \item 通道计时，用于记录中断间隔
    \end{itemize}
\end{itemize}

\section{功能描述}
\label{sec:anacom-func-descr}

\subsection{参考电压配置}
\label{subsec:anacom-vref-config}

模拟电压比较器的参考电压可选内部参考电压或者外部参考电压。根据参考电压来源不同，比较模式分为以下两种：
\begin{itemize}
    \item \textbf{内部参考电压模式}：设置 \hyperref[fielddesc:PADCOMPMODE]{PAD\_COMP\_MODE} = 0，将输入电压与内部参考电压进行比较。

    在此模式下，4 个 PAD 均可分配给通道作为输入，但由于硬件仅支持 3 个通道，因此最多使用 3 个 PAD。

    内部参考电压由 \hyperref[fielddesc:PADCOMPDREF]{PAD\_COMP\_DREF} 配置：
    \begin{itemize}
        \item 计算公式：VREF = PAD\_COMP\_DREF × 0.1 × VDDPST\_3 (V)
        \item 范围：0 \verb+~+ (0.7 × VDDPST\_3) V
        \item 步长：(0.1 × VDDPST\_3) V
    \end{itemize}
    其中 VDDPST\_3 为比较器 PAD 所在数字 HP IO 电源域的供电电压，由 VDDPST\_3 管脚输入，通常为 3.3 V。
    内部参考电压支持迟滞功能，可提高比较器在临界区域的稳定性。当 \hyperref[fielddesc:PADCOMPHYSEN]{PAD\_COMP\_HYS\_EN} = 1 时启用迟滞。\hyperref[fielddesc:PADCOMPHYS]{PAD\_COMP\_HYS} 配置迟滞电压 V\_HYS。
    
    当 PAD\_COMP\_OUT 为低电平时，内部参考电压为 VREF + V\_HYS；当 PAD\_COMP\_OUT 为高电平时，内部参考电压为 VREF。表 \ref{tab:anacom-hys-values} 列出了 V\_HYS 与 \hyperref[fielddesc:PADCOMPHYS]{PAD\_COMP\_HYS} 的对应关系。
    \begin{table}[H]
    \centering
    \caption{V\_HYS 取值}
    \label{tab:anacom-hys-values}
    \begin{tabular}{ | L{4cm} | L{4cm} | }
    \hline
    \rowcolor{lightgray}
    \textbf{PAD\_COMP\_HYS} & \textbf{V\_HYS} \\ \hline
    0 & 0 V \\ \hline
    1 & 0.04 V \\ \hline
    2 & 0.08 V \\ \hline
    4 & 0.12 V \\ \hline
    3、5、6、7 & 保留 \\ \hline
    \end{tabular}
    \end{table}

    \item \textbf{外部参考电压模式}：设置 \hyperref[fielddesc:PADCOMPMODE]{PAD\_COMP\_MODE} = 1，将输入电压与外部参考电压进行比较。

    在此模式下，需要从 4 个 PAD 中选择 1 个作为外部参考电压源，剩余 3 个 PAD 可分配给 3 个通道作为输入。

    通过 \hyperref[fielddesc:PADCOMPVREFCHANNELSEL]{PAD\_COMP\_VREF\_CHANNEL\_SEL} 选择外部参考电压源 PAD。该字段为 4-bit bitmap，由高到低依次对应 PAD3、PAD2、PAD1、PAD0，且仅允许一个 bit 为 1。

    \begin{tiplisting}
    用作外部参考电压源的 PAD 不应同时分配给任何通道作为输入 PAD。
    \end{tiplisting}

\end{itemize}

\subsection{控制器}
\label{subsec:anacom-controller}
             
控制器 (PAD COMP Controller) 支持轮询扫描，按通道编号顺序（1 → 2 → 3）依次扫描已启用的通道。


\begin{itemize}
    \item \textbf{输入 PAD 分配}：通过 \hyperref[fielddesc:PADCOMPCHANNEL1SEL]{PAD\_COMP\_CHANNEL\_X\_SEL} (X = 1, 2, 3) 为每个通道选择输入 PAD。
    
    该字段为 4-bit bitmap，由高到低依次对应 PAD3、PAD2、PAD1、PAD0，且仅允许一个 bit 为 1。
    
    \begin{tiplisting}
    各通道必须选择不同的 PAD。在外部参考电压模式下，用作外部参考电压源的 PAD 不可同时分配给任何通道。
    \end{tiplisting}

    \item \textbf{启用通道}：通过 \hyperref[fielddesc:PADCOMPPOLLMASK]{PAD\_COMP\_POLL\_MASK} 选择哪些通道参与扫描。
    
    该字段为 3-bit bitmap，由高到低依次对应通道 3、通道 2、通道 1。对应 bit 为 1 表示启用该通道，未启用的通道将在扫描过程中被跳过。

    \item \textbf{扫描触发与模式}：扫描可由软件通过 \hyperref[fielddesc:PADCOMPSTART]{PAD\_COMP\_START} 触发，或由 ETM 任务 PAD\_COMP\_TASK\_START 触发。扫描行为由 \hyperref[fielddesc:PADCOMPPOLLMODE]{PAD\_COMP\_POLL\_MODE} 控制：
      \begin{itemize}
        \item 0：全扫描模式。每次触发时，依次扫描所有已启用通道。
        \item 1：单步轮询模式。每次触发时，仅扫描下一个已启用通道。
      \end{itemize}
            

    \item \textbf{通道切换等待时间}：由于 Voltage Comparator 为复用模块，切换输入通道时需要一定的稳定时间，由 \hyperref[fielddesc:PADCOMPPOLLPERIOD]{PAD\_COMP\_POLL\_PERIOD} 控制，单位为 PAD\_COMP\_CLK 时钟周期，通常为 1 $\mu$s。
            
    \item \textbf{通道状态与毛刺过滤}：为避免输入通道处于参考电压临界区时产生毛刺，模块支持毛刺过滤。稳定时间结束后，根据通道状态 \hyperref[fielddesc:PADCOMPCHANNEL1STATUS]{PAD\_COMP\_CHANNEL\_X\_STATUS} 对 PAD\_COMP\_OUT 进行毛刺过滤。

    若当前状态为高电平，则需要连续采集到 \hyperref[fielddesc:PADCOMPLIMITCNT]{PAD\_COMP\_LIMIT\_CNT} 个低电平，才会切换为低电平。反之，若当前状态为低电平，则需连续采集到 \hyperref[fielddesc:PADCOMPLIMITCNT]{PAD\_COMP\_LIMIT\_CNT} 个高电平，通道状态才会切换为高电平。

    PAD\_COMP\_OUT 发生一次跳变并触发中断后，\hyperref[fielddesc:PADCOMPFILTERCNT]{PAD\_COMP\_FILTER\_CNT} 配置一段以 PAD\_COMP\_CLK 时钟周期为单位的去抖时间，在此期间不再触发新的中断，从而抑制输入电压在参考电压附近抖动导致的重复中断。\hyperref[fielddesc:PADCOMPLIMITCNT]{PAD\_COMP\_LIMIT\_CNT} 与 \hyperref[fielddesc:PADCOMPFILTERCNT]{PAD\_COMP\_FILTER\_CNT} 配合使用：前者在采样阶段过滤毛刺，后者在中断触发后抑制重复中断。

    \item \textbf{通道中断}：中断由通道状态的变化触发：
            \begin{itemize}
                \item 当 \hyperref[fielddesc:PADCOMPCHANNEL1STATUS]{PAD\_COMP\_CHANNEL\_X\_STATUS} 发生低到高的变化时，触发 \hyperref[int:PADCOMPnALLINT]{PAD\_COMP\_CHANNEL\_X\_INT} 和 \hyperref[int:PADCOMPnPOSINT]{PAD\_COMP\_CHANNEL\_X\_POS\_INT}
                \item 当 \hyperref[fielddesc:PADCOMPCHANNEL1STATUS]{PAD\_COMP\_CHANNEL\_X\_STATUS} 发生高到低的变化时，触发 \hyperref[int:PADCOMPnALLINT]{PAD\_COMP\_CHANNEL\_X\_INT} 和 \hyperref[int:PADCOMPnNEGINT]{PAD\_COMP\_CHANNEL\_X\_NEG\_INT}
            \end{itemize}
            
   \item \textbf{通道 ETM 事件}：当 \hyperref[fielddesc:PADCOMPCHANNEL1EVENTTIMEREN]{PAD\_COMP\_CHANNEL\_X\_EVENT\_TIMER\_EN} = 1 时，ETM 事件在中断触发后延迟 \hyperref[fielddesc:PADCOMPDELAYEVENTTIME]{PAD\_COMP\_DELAY\_EVENT\_TIME} 个 PAD\_COMP\_CLK 时钟周期产生：
            \begin{itemize}
                \item PAD\_COMP\_DELAY\_EVENT\_CHANNEL\_X\_POS：对应 \hyperref[int:PADCOMPnPOSINT]{PAD\_COMP\_CHANNEL\_X\_POS\_INT}
                \item PAD\_COMP\_DELAY\_EVENT\_CHANNEL\_X\_NEG：对应 \hyperref[int:PADCOMPnNEGINT]{PAD\_COMP\_CHANNEL\_X\_NEG\_INT}
            \end{itemize} 

    \item \textbf{通道计时器 (Channel Timer)}：当 \hyperref[fielddesc:PADCOMPCHANNELTIMEREN]{PAD\_COMP\_CHANNEL\_TIMER\_EN} = 1 时，通道计时器按照 PAD\_COMP\_CLK 持续计数。每当 \hyperref[int:PADCOMPnALLINT]{PAD\_COMP\_CHANNEL\_X\_INT} 产生时，当前计数值会保存到 \hyperref[fielddesc:PADCOMPCHANNEL1TIMER0]{PAD\_COMP\_CHANNEL\_X\_TIMER0}，同时将之前的 TIMER0 值保存到 \hyperref[fielddesc:PADCOMPCHANNEL1TIMER1]{PAD\_COMP\_CHANNEL\_X\_TIMER1}，从而记录两次中断的时间间隔。
        
\end{itemize}

图 \ref{fig:anacom-full-scan-timing} 展示了全扫描模式下的多通道扫描时序。本例配置为：\hyperref[fielddesc:PADCOMPPOLLMODE]{PAD\_COMP\_POLL\_MODE} = 0，\hyperref[fielddesc:PADCOMPPOLLMASK]{PAD\_COMP\_POLL\_MASK} = 3'b111（3 个通道全部启用），\hyperref[fielddesc:PADCOMPPOLLPERIOD]{PAD\_COMP\_POLL\_PERIOD} = 4，\hyperref[fielddesc:PADCOMPLIMITCNT]{PAD\_COMP\_LIMIT\_CNT} = 5，\hyperref[fielddesc:PADCOMPCHANNEL1SEL]{PAD\_COMP\_CHANNEL\_1\_SEL} = 4'b0001，\hyperref[fielddesc:PADCOMPCHANNEL2SEL]{PAD\_COMP\_CHANNEL\_2\_SEL} = 4'b0010，\hyperref[fielddesc:PADCOMPCHANNEL3SEL]{PAD\_COMP\_CHANNEL\_3\_SEL} = 4'b0100。

\begin{figure}[H]
    \centering
    \includegraphics[width=1\textwidth]{\modulefiles/figures/anacom_full_scan_timing.png}
    \caption{模拟电压比较器全扫描模式时序图}
    \label{fig:anacom-full-scan-timing}
\end{figure}

\begin{itemize}
    \item 图中蓝色底色区域为 WAIT\_x 阶段：PAD 通道已切换，等待 \hyperref[fielddesc:PADCOMPPOLLPERIOD]{PAD\_COMP\_POLL\_PERIOD} 个周期让比较器输出稳定。
    \item 红色底色区域为 CHANNEL\_x 阶段：采样比较器输出，持续 \hyperref[fielddesc:PADCOMPLIMITCNT]{PAD\_COMP\_LIMIT\_CNT} 个周期，正/负方向独立计数。
    \item 黄色高亮值表示定时器匹配值（触发状态转换）。
\end{itemize}

全扫描模式下，状态机依次遍历所有 \hyperref[fielddesc:PADCOMPPOLLMASK]{PAD\_COMP\_POLL\_MASK} 使能的通道（WAIT $\rightarrow$ CHANNEL），全部完成后返回 IDLE。单步轮询模式（\hyperref[fielddesc:PADCOMPPOLLMODE]{PAD\_COMP\_POLL\_MODE} = 1）下，每次触发仅完成一个通道后即返回 IDLE，下次触发继续轮询下一个使能通道。

    \item PAD\_COMP\_CLK：用于模块功能运行的时钟，由 \hyperref[fielddesc:HPSYSCLKRSTPADCOMPCLKEN]{HP\_SYS\_CLKRST\_PAD\_COMP\_CLK\_EN} 使能

\section{事件任务矩阵}
\label{sec:anacom-etm-func}

在 \chipname{} 中，模拟电压比较器支持 ETM 功能。该模块可产生 ETM 事件，用于触发其他外设的 ETM 任务。关于 ETM 更多详细信息，请参考章节 \ref{mod:evntaskmatrix} \nameref{mod:evntaskmatrix}。这里仅介绍与模拟电压比较器相关的 ETM 事件与任务。

模拟电压比较器可产生的 ETM 事件包括：

\begin{itemize}
    \item PAD\_COMP\_DELAY\_EVENT\_CHANNEL\_X\_POS：通道 X 的 PAD\_COMP\_OUT（经毛刺过滤）由低电平变为高电平，即输入电压从低于参考电压变为高于参考电压。
    \item PAD\_COMP\_DELAY\_EVENT\_CHANNEL\_X\_NEG：通道 X 的 PAD\_COMP\_OUT（经毛刺过滤）由高电平变为低电平，即输入电压从高于参考电压变为低于参考电压。
\end{itemize}

模拟电压比较器可接收的 ETM 任务包括：
\begin{itemize}
        \item PAD\_COMP\_TASK\_START：触发通道扫描。根据 \hyperref[fielddesc:PADCOMPPOLLMODE]{PAD\_COMP\_POLL\_MODE} 配置：当其为 0 时，每次触发对所有已启用通道完成一次扫描；当其为 1 时，每次触发仅对下一个已启用通道完成一次扫描。
\end{itemize}

\section{配置流程}
\label{sec:anacom-prog-procedures}

软件配置模拟电压比较器功能的流程如下：


\begin{enumerate}
    \item 将 \hyperref[fielddesc:HPSYSCLKRSTPADCOMPAPBCLKEN]{HP\_SYS\_CLKRST\_PAD\_COMP\_APB\_CLK\_EN} 设置为 1，使能总线时钟 APB\_CLK。
    \item 将 \hyperref[fielddesc:HPSYSCLKRSTPADCOMPCLKEN]{HP\_SYS\_CLKRST\_PAD\_COMP\_CLK\_EN} 设置为 1，使能功能时钟 PAD\_COMP\_CLK。
    \item 将 \hyperref[fielddesc:PADCOMPXPD]{PAD\_COMP\_XPD} 设置为 1，上电并启用电压比较器。
    \item 配置参考电压：选择内部或外部模式，并设置相应参数（参考 \ref{subsec:anacom-vref-config} \textit{\nameref{subsec:anacom-vref-config}}）。    
    \item 如果选择外部参考电压模式，需要禁用用作外部参考电压源的 PAD 的数字功能，包括 IE、OE、WPU 和 WPD。具体配置方式请参考章节 \ref{mod:iomuxgpio} \textit{\nameref{mod:iomuxgpio}} 中的 \ref{subsec:analog_func_config} \textit{\nameref{subsec:analog_func_config}} 小节。
    \item 配置控制器：分配通道输入 PAD、启用通道、设置扫描模式等（参考 \ref{subsec:anacom-controller} \textit{\nameref{subsec:anacom-controller}}）。
    \item 通过 \hyperref[fielddesc:PADCOMPSTART]{PAD\_COMP\_START} 或 PAD\_COMP\_TASK\_START 触发扫描并获取比较结果。
\end{enumerate}
